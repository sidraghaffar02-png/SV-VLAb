# Delivery Robot Requirements

| Req-ID | Description | Priority |
|---|---|---|
| R-01 | The robot shall remain in the IDLE state when it is switched on and no delivery request is received. | High |
| R-02 | The robot shall start navigating toward the destination after receiving a delivery request. | High |
| R-03 | The robot shall continuously monitor its surroundings for obstacles while navigating. | High |
| R-04 | The robot shall enter obstacle-avoidance mode when an obstacle is detected. | High |
| R-05 | The robot shall continue navigating toward the destination after successfully avoiding an obstacle. | High |
| R-06 | The robot shall start the delivery process after reaching the destination. | High |
| R-07 | The robot shall return to the warehouse after successfully delivering the package. | High |
| R-08 | The robot shall stop the current delivery journey and return to the warehouse when the battery becomes critically low. | High |
| R-09 | The robot shall become idle after reaching the warehouse. | High |
| R-10 | The robot shall not enter the delivery process directly from IDLE or while avoiding an obstacle. | High |
